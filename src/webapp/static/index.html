        Les 5 consignes de tri

        Chaque produit est classé dans l'une de ces 5 catégories strictes.

        Poubelle JAUNE

        Emballages ménagers légers : bouteilles, canettes, boîtes de conserve, briques, flacons, cartons.

        plastique · métal · carton

        Poubelle VERTE

        Uniquement le verre d'emballage : bouteilles de jus/vin, pots de confiture, bocaux. Vaisselle cassée interdite.

        verre

        Poubelle BLEUE

        Papiers graphiques propres : prospectus, journaux, magazines, cahiers, livres, enveloppes.

        papier

        Bac Électronique (D3E)

        Tout produit à piles, batterie ou prise : smartphones, écouteurs, chargeurs, mixeurs, montres.

        équipements électriques et électroniques

        Poubelle MARRON / NOIRE

        Déchets résiduels : restes alimentaires, emballages souples, produits d'hygiène, objets multicouches.

        déchets résiduels
